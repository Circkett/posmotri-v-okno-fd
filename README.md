# Привет! Это мой второй проект для прохождения учёбы в Яндекс Практикуме.

## О чём проект?

Проект представляет из себя инструмент для просмотра "в окно" выбранного города.

## Инстртрукция

1. В инпуте поиска написать любой город
2. Выбрать время суток: Утро, День, Вечер, Ночь
3. Нажать на кнопку "Войти"

Далее можно запустить видео города в выбранное время суток
